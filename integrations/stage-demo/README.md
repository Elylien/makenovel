# 第六轮原生演出验证样片生成器

用锁定 WebGAL 原生脚本生成独立开发样片：两名可区分的角色、各两种表情、站位、轻跳、平移、BGM / SE / voice 通道、等待、背景交叉淡化、黑场与两条分支。所有角色、背景和测试音均由本目录的代码生成，无第三方录音或商业图片。

这是开发占位样片。voice 通道播放高低不同的 PCM 音序列，**不是语音，更不代表真人配音、正式美术或声音审美验收通过**。背景/角色 SVG 使用系统 sans-serif 字体绘制少量英文标识，无外部字体和网络资源引用。

## 生成与验证

需要已初始化的锁定 WebGAL 子模块、已构建的原生 parser、Node.js，以及已经存在的目标父目录。游戏通过本项目受控构建的共享引擎运行；生成器不会复制或构建引擎。

```powershell
node integrations/stage-demo/generate.mjs --output .local/editor-profile/games/makenovel-round6
node integrations/game-manifest/cli.mjs verify --game .local/editor-profile/games/makenovel-round6
node --test integrations/stage-demo/stage-demo.test.mjs
```

生成器拒绝任何已经存在的输出路径，不更新旧作品、不复用旧身份。再次验证不同生成结果时，显式使用新的目录名。角色/音频/脚本内容可重现；每个新作品的 `Game_key` 和首次封存生成的 `projectId` 独立随机，避免玩家进度串档。生成后已有作品改稿仍需显式 `seal --update`，不会自动封存作者后续修改。

仅从 WebGAL 锁定提交 `d0318e6c4cdb8b04bb5d891f40368cff3c6efc85` 通过 `git show` 取出四个 GUI 模板文本文件和 MPL-2.0 许可证，忽略 vendor 工作区修改，不复制其立绘、背景、BGM、语音或字体。新作品根目录有模板哈希和身份收据 `stage-demo-receipt.json`、`ASSET-CREDITS.txt` 与 `WEBGAL-LICENSE.txt`。`game/` 中的十八个文件由 manifest 登记。上游模板归 WebGAL 原作者，遵循 MPL-2.0；本生成代码及原创生成资产按本项目 MPL-2.0 提供。共享引擎自身资产的许可仍以其原始条款为准。

## 停靠点

手动模式下逐条点击；自动模式会按原生规则继续，不应把台词编号视为程序断点。

| 台词编号 | 验证内容 |
| --- | --- |
| R6-01 | 左侧林：橙色上衣、裙装；右侧羽：蓝外套、长裤；两者同时在场 |
| R6-02 / 03 | 不同音高的 voice 测试音，BGM 同时存在；检查语音/音乐音量分组 |
| R6-04 | 短 SE 音；下一次推进切换表情 |
| R6-05 | 两个笑脸，位置不变；下一次推进林轻跳两次 |
| R6-06 | 下一次推进开始羽的 8 秒平移及 `wait:8000 -nobreak`；打开菜单/设置、关闭菜单、回标题、读档等中断检查入口 |
| R6-07 | 平移完成；可保存，继续到夜景后读档对比位置/表情/音频 |
| R6-08 | 1.6 秒日夜背景交叉淡化完成，角色仍在场；下一步退场至黑色背景 |
| R6-09 | 黑场、人物退场、BGM 淡出；下一步恢复日景、两角色和 BGM，并显示分支 |
| R6-A / B | 左/右两个选项分别设置 `round6_route=1/2`，有对应角色表情与 voice 测试音 |
| R6-10 / 11 | 汇合显示路线值；可选择再做 8 秒菜单测试，或结束回标题 |

`-nobreak` 只禁止点击截短等待，不是禁止菜单操作。菜单打开期间是否应暂停演出、退出时是否清除旧动画/音频，由真实引擎行为验收，生成器不改变运行时。跳跃总长 860 毫秒，后接 1 秒等待；背景转场后留有可观察等待。角色差分 SVG 尺寸相同，满足原生差分交叉混合的几何条件，但实际 GPU 资源是否就绪仍需浏览器 / EXE 验证。

## 检查范围

测试直接使用已构建原生 parser 和实际运行时 `assetSetter.ts`，确认媒体地址、分支目标、等待/演出参数；检查 WAV 头/幅度、原创资源可重现性、无 SVG 外链、封存完整性、两次生成身份隔离以及拒绝覆盖既有作品。测试使用 `.scratch/` 下的独立夹具，不操作用户作品。

这些测试不证明浏览器自动播放权限、菜单演出生命周期、音量混合、差分实际混合效果、EXE 音频输出、存档恢复或快进表现通过；需要在编号停靠点进行真实交互验证。生成目录和玩家进度不提交 Git。
