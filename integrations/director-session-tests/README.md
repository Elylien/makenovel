# 导演局部会话回归

运行 `node integrations/director-session-tests/run-tests.mjs`。使用 Terre 已安装的 esbuild，将实际会话、共享文档和锁定 WebGAL parser 打成浏览器目标模块，再由 Node 测试；没有另写剧情解析器或文件保存器。

当前 82 项覆盖已有原生演出命令的有限分组、条件/分支/高级/多行边界、未知源码和注释保留、局部身份按需登记、取消及无变化应用、整份源码与历史代数拒绝过期写入、原生语义往返，以及共享文档的一步撤销/重做、dirty 持久副本与保存前预览隔离。

第八轮允许新增完整单行 `changeBg`、`changeFigure`、`bgm`、`playEffect`，仅插在所选对白及其独立身份标记前。新增命令调用原有 `insertSceneStatement`，随后校验原生解析列表中的新命令语义和所有原句语义/位置；当轮只支持撤掉本次新行，第十轮增加下述已有行操作。新增静态主图限 png/jpg/jpeg/webp/svg，音频限 mp3/ogg/wav/opus，或明确 `none`；空素材、翻译占位、插值、未知参数和注释/身份注入被拒绝。新增差分、视频与模型不在本轮范围。

插入和撤掉显式映射原行位置，保留其会话身份；未编辑原行不会因为移行而新增标记。覆盖多个新行的顺序撤掉、移行后编辑原对白、迟到的已移除身份、改回原文、混合换行/BOM/注释和独立旧身份标记，以及多个插入与修改只产生一步共享撤销。

只读来源是当前场景可证明线性前文中的最近命令，不执行第二套剧情。可越过简单对白、等待及注释；控制流、标签、动作、未知参数、条件或插值构成边界。分清本组与更早来源、明确 `none`、本场景未见及边界未知。锁定 parser 会把 `none` 和空 token 都解析成空串，因此只有原生解析为空且已验证源码明确写 `none` 时才标关闭。差分依赖实际目标及模型类型，其源码可见但结果始终未知；效果音来源不承诺仍在播放。

第九轮新增 13 项只读定位契约回归。来源与返回对白绑定同一份完整源码及历史代数；已登记身份由真实源码提取，未登记行只在该精确快照内以行号和原文定位，不写入会话预留 ID。完整草稿尚未应用、伪造来源事实、无具体来源、原文或身份改变、移行，以及撤销重做回到同文的 ABA 均被拒绝。明确关闭和具有具体源码的差分可定位，边界导致的无来源未知不能制造目标。覆盖 BOM/CRLF/独立旧标记、重复语句、返回原对白、局部修改恢复原文，以及重复定位不触发共享文档通知、历史、持久草稿或保存。场景切换、输入缓冲和实际滚动/聚焦由图形界面集成另行验证。

第十轮新增 18 项已有设置删除与相邻重排契约回归。`directorStructuralActions` 提供当前局部能力与不能操作的原因；`deleteDirectorSessionNode` 仅删除安全舞台/声音命令，`moveDirectorSessionNode` 只交换物理相邻的完整原生块。含变量插值或 `continue` 的设置拒绝结构操作；独立注释、空行、等待、对白和高级边界不可跨越。旧的 `removeDirectorSessionNode` 仍仅撤掉本次新增，保持原契约。

删除将行内作者注释原字节保留为独立只读行，移除被删命令身份及其紧邻 legacy 标记；注释取得新的局部预留身份，旧命令回调不能落到它上面。裸语句结束符和仅包含身份标记的尾部可以去除，其他空格和分号不按作者意图猜测清理。重排携带原块的身份、行内注释和换行；独立 legacy 元数据随所属命令一起移动。未登记命令不会因删除或移行登记 ID，字节相同的相邻交换保持整个会话不变，往返交换恢复精确源码。

所有结构操作都通过既有原生解析范围和 `applySourceChanges` 定位；随后重新运行锁定 parser，校验整个场景每条保留语句的语义和映射后位置，包括面板外源码。来源摘要随删除和重排重新计算，删除 `none` 不伪造关闭状态；混合结构操作、新增和正文修改仍一次进入共享文档、一次撤销/重做，完整源码及历史 ABA 守卫不变。源码分析按不可变会话缓存，避免只读控件渲染逐项重解析整场景。

测试中的 transport 和草稿存储为内存替身，未读写作者作品；会话修改调用的是产品 `editGraphicalStatement`、真实锁定 parser 和 `SceneDocument`。这不代替浏览器表单、真实中文输入、磁盘并发或播放器实测。

保持现有保守入口：未知参数、未知命令、多行或条件语句是分组边界；等待与独立注释只读。选中对白不接受 `when`、`next`、`continue`、`concat`、`notend`。原分析器把 BOM 所在首行命令视为高级源码时，本面板也保留该边界；修改其他行仍精确保留 BOM 与首行原字节。
