# 第十一轮导演等待时序样片

独立新建用于等待时长、点击跳过和整批草稿验证的作品。复用 `integrations/stage-demo/generate.mjs` 的纯素材工厂，背景标识改为 `ROUND 11`；不运行旧生成器、不读取或覆盖旧作品。每次新建使用独立 `Game_key` 和 `projectId`。

```powershell
node integrations/director-timing-demo/generate.mjs --output .local/editor-profile/games/makenovel-round11
node integrations/game-manifest/cli.mjs verify --game .local/editor-profile/games/makenovel-round11
node --test integrations/director-timing-demo/director-timing-demo.test.mjs
```

目标父目录须已存在且为普通目录，任何已存在的目标都拒绝覆盖。作品沿用经过审查构建的共享引擎，四个 GUI 模板文本及许可取自锁定 WebGAL 提交。素材为原创 SVG 与 PCM 诊断音，没有商业图片、音乐或真人录音；计时对白不绑定语音，以减少观察干扰。运行时构建期间不要执行生成器、封存或测试，以免与 parser 产物重建冲突。

`start.txt` 共 23 行，首行含 UTF-8 BOM，全部行及末尾使用 CRLF。第 2–6 行建立日景、BGM 和双角色，第 7 行 `R11-BEFORE` 是第一段正常播放的起点。三个等待都由夜景开始、日景结束，便于从原生画面和目标对白观察进展；生成器不添加计时脚本或替代执行器。

| 初始位置 | 配置与用途 |
| --- | --- |
| 第 8–12 行 | 第一段：立即切夜景，开始 `800` 毫秒立绘切换，执行 `wait:2000 -nobreak`，再切日景并显示 `R11-LOCKED`。等待有行内身份 `r11-locked-wait` 和作者注释 |
| 第 13–16 行 | 第二段：夜景、`wait:2500`、日景、`R11-SKIPPABLE`。等待没有持久身份，默认可点击提前结束；真正改动参数时才登记新身份 |
| 第 17–21 行 | 第三段：夜景、独立 legacy 身份与 `wait:1200 -nobreak`、日景、`R11-LEGACY`。用于核对原身份 `r11-legacy-wait`、标记位置和作者注释保留 |
| 第 22 行 | `R11-AFTER` 后继对白，没有自己的等待设置 |

第一段立绘的 `-next` 让原生执行器继续建立后面的等待，二者从同一批演出开始，`800 + 2000` 不能解释为总计 `2800` 毫秒。等待结束后才执行下一条日景命令。这里记录的是配置和锁定原生语义；资源加载、浏览器调度与实际观察误差须在 GUI 证据中单独记录，不能把测试通过当作精确墙钟测量。

建议先在第 12 行打开“舞台与声音”，修改第一段等待时长与点击跳过设置，检查注释、原身份、取消、一次应用及一次撤销/重做。第 16 行验证未登记等待在真正编辑后取得身份；第 21 行验证 legacy 标记保留。所有参数编辑完成并保存后，再沿原生播放器从第 7 行正常点击推进。不要用编辑器“执行到此句”的快速预览结果来证明等待时长。

计时观察从文字已经显示完整的前一句出发，以夜景上屏作为开始边界，以日景及下一句出现作为结束边界。第一段初始 `-nobreak` 阻止点击截短；第二段初始无此选项，可以分别观察不点击的完整等待和等待中点击的提前结束。自动播放需要等待结束；菜单中的计时仍会继续，但后续对白推进受菜单状态影响，因此基础计时关闭自动、快进和菜单。不同操作模式分别记录，不能混作同一测量。

`readonly.txt` 需在编辑器中明确打开，不从主场景自动进入，也不用作播放计时。第 3/5/8/10/12/14 行的目标对白之前分别有 `next`、`next=false`、变量时长、未知参数、`continue` 与条件等待。本轮控件不编辑这些时序形式；部分语句会成为收集边界，其他语句可显示为只读。原文必须保留，不将其规范化为普通静态等待。

生成收据 `director-timing-demo-receipt.json` 记录初始 manifest、作品身份、源码/config/模板哈希、每段等待及前后视觉边界和只读目标位置。时长字段是初始配置，生成收据不代表后续改稿或播放验收结论。实际改稿之后须显式重新封存；作品、玩家数据及本地证据不提交 Git。

3 项测试使用真实锁定 parser、runtime `assetSetter`、共享身份模块及 manifest 工具，覆盖等待参数与命令顺序、资产映射、混合/legacy 身份、BOM/CRLF/作者注释、只读语法原文、独立作品身份和拒绝覆盖。等待编辑事务由导演核心测试验证；正常播放时间、点击/自动/菜单行为、真实控件缓冲和 IME 需单独验收。
