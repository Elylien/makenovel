# 舞台与中断契约

第六轮沿用锁定 WebGAL 的原生脚本、舞台快照、PerformController、Pixi 和音频元素。本文件记录本轮有限行为，不表示全部转场、持续效果或插件已验收。测试结果另见 TESTING 和本轮证据。

## 菜单与剧情

设置、存读档菜单、历史、流程图、确认框、紧急回避遮罩和鉴赏覆盖剧情时，底层下一句入口拒绝玩家推进，不发送 `userInteractNext`，也不提前结束演出。

本轮选择**动画与声音继续计时，剧情等待菜单关闭**。没有声称冻结动画或暂停 BGM/语音。等待或动画自然结束产生的内部推进只保留一份；所有覆盖层关闭后，在微任务中核对会话、场景对象和语句位置，仍匹配才继续一次。手动推进优先于尚未消费的请求；读档、返回标题或新会话使旧请求失效。

这项策略适用于游戏菜单。浏览器后台标签节流、失焦暂停、操作系统音频设备切换仍是独立验证范围。

## 并行演出

同一轮并行动画结束和等待结束不能各自推进剧情。原生 controller 需要合并待推进请求，开始新一轮演算或清除会话时取消旧请求；批量卸载先移除旧实例和状态，再执行 stop，最后最多继续一次。取消后的旧定时器不能卸载同名新演出。

有限演出的 stop 到达原生终态；保持型演出保留其原生停止语义。背景与立绘退场对象按 UUID 登记到独立退出表，读档/重置时取消定时器并清除旧对象，迟到回调不能删除同键新对象。入场和退场时长分别取值。生命周期修改不能被当作任意插件的异常事务或渲染资源加载失败恢复。

## 声音

语音异步准备完成后必须重新核对播放请求是否仍有效。被推进、停止或读档替换的请求不得重新播放、恢复嘴型定时器或终止新语音。音效拒播必须释放自动播放阻塞；BGM 淡变与 UI 音效应清理旧回调并处理播放拒绝。

测试音只用于验证 BGM、SE 和语音通道。媒体元素播放/计时证据不等于扬声器试听、配音表现或音质验收。

## 保存的位置

本轮先采用保守门禁：有限背景/立绘变换、差分、动画或 wait 尚在活动列表、仍有退出对象，或菜单后仍有待继续剧情时，普通和快速保存明确拒绝，提示返回剧情并待演出结束后的对白处保存；不修改旧槽，也不暗中跳到更远进度。自动快存静默保留此前成功的记录。

对白和保持型环境效果继续走原生快照。正常稳定点读档恢复精确版本、场景栈、变量及舞台。第五轮已有的备份、版本隔离和持久化成功确认继续生效。

**尚未实现**最近稳定检查点自动回退保存或排队保存；不支持承诺任意毫秒视觉状态恢复。历史/流程图中的动画快照、旧版本已存在的演出中存档、保持型复杂效果和所有资源副作用仍需单独验证。本门禁不将这些范围变成兼容迁移或完整 AT 通过。

## 第七轮静态主图资源门禁

图片加载与演出、剧情时钟仍然独立。有限演出已经按 duration 结束，不表示纹理下载、解码、GPU 准备或挂载已经完成。第七轮在原生静态图片背景/立绘对象上记录 `pending / ready / failed`，只有主图片的 setup 完成才变为 ready；这些记录不写入原生存档格式。

当前非退场主图片仍 pending 时，普通与快速保存提示等待；主图片最终加载或挂载失败时，提示检查资源后重新打开作品。两者均拒绝生成新快照，不覆盖旧槽；静默自动快存继续保留此前记录。原生 loader 的首次失败可重试一次，本补丁没有增加持续自动重试。

状态由对象 UUID 与本次主请求的记录身份共同约束。同 key 新对象、同 UUID 的后续请求，以及移除/重置后的旧回调，不能互相覆盖就绪状态；临时资源持有者在成功或失败后释放。口型、眨眼等辅助纹理请求不改变主图片状态；正常舞台不会仅因未来剧情的预取失败而被禁止保存。已退场对象仍由独立退出门禁处理。

同 URL 的失败对象不会因为后续普通 stage commit 而隐式反复重试。修复资源后可重新打开作品，或先实际退场/切换成另一图片再显示；单独切换场景若保留同一个舞台对象，不等于重试。切换到正常新主图并完成挂载后可解除该资源门禁。真实浏览器先验证了损坏 SVG 持续 pending 时普通/快速拒存、旧槽不变和换回 day 后恢复保存；补入下述 SVG 错误传播修复并重建后，又验证了明确 failed 提示、普通/快速各自拒存和换回 day 后恢复保存。普通槽 1 的旧字符串保持完全相等，快读仍回到 R7-BASE；重走故障并换图后，快档预览为 R7-RECOVER，普通新槽 3 成功保存。最终 Windows 包在开发服务全程停止时独立完成同类故障路径：坏 SVG 明确 failed，普通/快速拒存且原槽不变，快读回 R7-BASE；换回 day 后恢复普通/快速保存，正常退出并重启后槽 2 恢复 R7-RECOVER 和两角色。浏览器与 EXE 的这些有限实测分别记录，不等于全机断网、干净机器或异常退出耐久性。

浏览器中的损坏 SVG 暴露了锁定 Pixi 的错误传播缺口：`SVGResource` 发出 `onError`，但自身 `load()` Promise 不结束，使舞台一直 pending。生产 `assetParsers` 现在仅对实际 `SVGResource` 监听 `BaseTexture` 的公开 error 事件，将原错误对象传给 Promise rejection；成功、原生拒绝、同步抛错或事件失败均释放本次监听，迟到结果只处理一次。非 SVG 保留原加载路径，失败仍走既有纹理销毁与缓存清理，没有修改依赖或加入超时。

`integrations/resource-lifecycle-tests/` 通过 **38/38**：原有 28 项编译真实 PixiController 的主图创建、加载、移除方法、舞台同步和普通/快速保存入口，仅替换网络/GPU/渲染容器与持久化边界；新增 10 项接真实 assetParsers 与锁定 Pixi 的 SVGResource、ImageResource、BaseTexture、Texture，仅替换 Image/canvas 和 Assets 注册边界。同套件原 28 项加载第六轮原文件为 **6 通过 / 22 失败**；最终 38 项仅恢复桥接前 assetParsers 为 **31 通过 / 7 失败**。

原 28 项检查演出列表已清空时的拒存、缓存命中、有限重试、实际立绘挂载异常、同步/异步 setup 异常、过时结果、辅助图隔离、重置与旧槽保留；新增 10 项检查 SVG 原生 Promise 不结束时的 error 桥接、原错误身份、监听释放、并发隔离、迟到原生拒绝、非 SVG 行为及失败后同 URL 的真实 Texture.from 缓存清理与新资源创建。这些方法边界测试不替代浏览器实际解码或音画时钟的完整验收。

GIF、视频、Live2D、Spine、GPU 上下文丢失、永久无响应的资源超时、插件副作用与全场景加载事务仍未覆盖。SVG onload 中的零尺寸或 drawImage 异步抛错若不发出 onError，也未由本次桥接处理。本门禁不会暂停或回滚剧情，不提供超时、重试按钮、排队保存或稳定检查点回退。

## 可复现样片

`integrations/stage-demo/` 提供单独作品生成入口。原创 SVG 角色/背景和 PCM 测试音由源码生成，原生 GUI 模板来自已锁定上游；没有商业游戏素材。样片按编号对白提供停靠点，保留明确时长的等待与双路线，便于比较正常、菜单、快进和恢复终态。

`integrations/director-demo/` 生成独立第七轮作品，不覆盖旧轮。`R7-01/02` 用于相邻命令的导演编辑；`R7-BASE → R7-FAIL → R7-RECOVER` 提供正常主图、损坏主图、重新换图的停靠点。`broken.svg` 文件存在且已封存，但内容不是有效图像，避免漏文件先被完整性校验拒绝而测不到运行时资源门禁。生成器的 3 项真实 parser/manifest 测试通过；上述浏览器故障路径另有实际观察，不能由生成器通过推导。第七轮导演 GUI 已完成取消、整步撤销/重做、保存重开及原生预览；最终 Windows 包也独立通过上述故障、恢复保存与正常重启读档路径，详见 [第七轮证据](evidence/2026-10-08-round7.md)。真实 Windows 中文 IME 仍未验收。
