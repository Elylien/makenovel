## 第八轮现场补充

## 第十三轮静态立绘范围

新转场输入限定普通单行静态图片、标准单位置和静态非保留 ID，保留原有收集边界。普通立绘默认入场 200 / 下次退场 160 毫秒，退出设置属于旧对象的此前显示命令。位置和 ID 修改不等同移动现有舞台对象；无 ID 换槽不会自动关闭原槽。相同目标、图片、位置再次执行不会重新淡入，next 也不表示等转场完成再推进。

模型、差分、自定义动画、关联口型眨眼、分数位置及完整 setAnimation 编辑仍是独立工作。新参数修改与素材/对白一起留在局部草稿，具体通过与未运行项目见 [第十三轮证据](evidence/2026-10-09-round13.md)。本轮代码不能代替 Windows 离线与完整自动/快进/菜单组合验收。

本轮额外观察：编辑器执行到此句建立锚点后，末段一次快速读档未观察到RIGHT恢复，原因未确认；正常首次读回及整页重开后读回均成功。该混合预览路径未计为通过，下一轮先复查该组合，再扩展独立动画。 记录见 `docs/evidence/local/round13/gui-observations.json`，没有据此改动原生存档协议。
