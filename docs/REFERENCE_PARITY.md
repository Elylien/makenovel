## 取证与更新方式

1. 在已确认 Steam 中文版基础上，核查具体 build、更新/补丁状态和操作环境；资料不足时保留未知并继续独立工程工作，无需再次询问已确认的渠道与语言。
2. 每条事实记录官方页面或实际操作序列、日期、版本、截图/录制位置和观察者。官方概述支持某能力存在，不自动支持具体快捷键、时序或异常边界。
3. 在锁定的 WebGAL/Terre 上执行相同相关操作；代码位置用于解释差异，真实运行用于确认行为。先记录“已有但不一致”的具体差异，再决定复用或补丁。
4. 本项目完成后链接实现、对应 AT 和证据；音画/审美待人工复核时仍保留该状态。
5. 若一直缺少精确参考版本，可以交付明确范围的阶段版本；不得宣称“原作全部功能已对标完成”。
