# 第四轮：场景历史、草稿恢复与播放器画布

日期：2026-10-07。版本 `0.0.4`。两份上游提交和依赖锁均保持原值；本页只记录第四轮的实现与验证，第三轮 Windows EXE 证据不作本轮结果使用。

## 实现

- 图形与源码共用每场景的撤销/重做历史，保存后仍可撤销；历史只在当前页面保留。默认上限 100 步、2 MiB UTF-16 文本增量，超大操作仍保留当前草稿，但可能清空不可达的旧历史。
- 连续源码输入合并，粘贴与图形操作分步；Monaco 原生快捷键、菜单历史和组合输入接入同一文档。跨作品的同名场景重新绑定正确的编辑器实例。
- sessionStorage 继续支持标签页刷新恢复；localStorage 按工作区、场景和文档实例分别保存副本。关闭页面后由作者主动选择恢复，旧版本副本进入冲突状态，不能自动覆盖磁盘。容量或权限失败提示下载备份，其他窗口副本不会被清除。
- 新客户端提交工作区前置条件。后端在读取和保存事务中捕获工作区，拒绝切换后在另一工作区同名、同字节文件上的误保存。旧客户端的该字段仍为可选，因此不能宣称所有历史客户端都获得了相同保护。
- 播放器根画布改为固定定位，消除菜单聚焦导致 body 滚动和整体上移。受控 runtime 构建生成源码/产物凭据；编辑器构建先检查凭据，构建后同步共享模板，并保留旧模板备份。

## 播放器实测

使用原生演示场景复现：在 1280×720 浏览器中进入游戏并打开存档菜单，修复前 body 的 scrollTop 为 332.666656，根画布和菜单 y 为 -332.666687；修复后同操作 scrollTop 和 y 均为 0。

| 浏览器视口 | 修复后根画布和菜单 | body 滚动 |
| --- | --- | --- |
| 1280×720 | (0, 0)，1280×720 | 0 |
| 1600×900 | (0, 0)，1600×900 | 0 |
| 1280×960 | (0, 120)，1280×720 | 0 |

这是浏览器视口回归，未覆盖真实 Windows DPI、所有全屏行为或重新打包后的 EXE。截图与原始 DOM 测量在本地 `docs/evidence/local/round4/menu-*`，不上传公共仓库。

## 构建与同步检查

受控 runtime 构建通过；全流程 174.1 秒，其中上游 Yarn 构建 97.9 秒。25 个非 game 引擎文件同步至 Terre 共享模板，模板 game 文件逐一哈希不变。缺失凭据、过期源码凭据、产物被额外修改三个负例均被拒绝；测试改动随后恢复。

同步不修改作者的 game 文件，但无自带 index.html 的普通作品会使用新的共享引擎；自带入口或衍生作品继续使用自己的引擎。操作顺序和恢复方式见 [引擎补丁与模板同步](../integrations/RUNTIME_PATCHES.md)。

## 实际编辑器操作

主夹具 `makenovel-round4-template` 只有 game 目录、没有自带 index.html，使用独立 Game_key；另一个本轮夹具用于检查作品间隔离。第三轮作品未改写。

1. 在图形对白框填写中文后立即 Ctrl+S，最终文字完整落盘；进入源码模式撤销，再进入图形模式确认旧文字；重做后重新显示“已保存”。另一次撤销期间磁盘摘要保持 `53f9e613dca05997352049ab0d07cf367144d9cf2967eb50c71ee217cabf4b3b`，证明撤销只改草稿。
2. 在 chapter-two 写入未保存对白后切换 start；状态条提示另一个场景草稿阻止预览。撤销 start 不改变 chapter-two 的草稿，两个场景独立。
3. 关闭实际浏览器标签页，重新创建新标签页。当前场景显示磁盘原文，“本机恢复副本”能列出关闭页面前的完整对白。磁盘摘要仍为初值。明确点击恢复后显示“尚未写入磁盘”，再点击保存才落盘。
4. 在 Monaco 末尾粘贴中文注释，Ctrl+Z 返回已保存状态，Ctrl+Y 恢复未保存内容，再撤销回到保存版本。测试注释未写入文件。
5. 在同一 SPA 经 Dashboard 打开另一个作品的同名场景，显示其原始对白，恢复面板不出现主夹具的副本；返回主作品内容与状态正确。该操作不等于覆盖所有路由/编辑器重挂载情况。
6. 普通作品通过运行中的 Terre 服务取得的 25 个非 game 引擎文件，逐一与构建凭据的 SHA256 一致。打开作品并进入存档菜单后，计算样式为 fixed，根画布 (0,0)、1280×720，body 滚动为 0。确认修复传播到了共享模板作品。

最终两个场景均已保存，BOM、身份标记与作者注释保留；start 为 10 个 CRLF，chapter-two 为 2 个 CRLF，两者均无独立 LF。证据在本地 `final-http-and-bytes.json`、`undo-disk-check.json`、`shared-template-menu.json`、`editor-recovered-draft.png` 和 `editor-ready.png`。

收尾保留编辑器 PID 33200，仅监听 `127.0.0.1:3001`；本轮 3000 预览已停止，全局 `.webgal_terre` 未创建。构建有上游 Sass API、较大 bundle 与 Jimp eval 警告，不影响本轮构建成功，也未将这些警告宣称为已修复。

## 范围

真实 Windows 中文输入法候选交互尚未验收；自动事件测试不能替代该验收。浏览器副本不是文件系统恢复仓，清理浏览器数据、容量不足、换 origin/profile 或移动工作区都会影响可见副本。历史栈不跨页面持久化。

[存档兼容审查](../SAVE_COMPATIBILITY.md) 已完成当前原生协议的核对与方案记录，本轮未实现旧玩家存档迁移。完整项目预检、资源/音频矩阵、干净 Windows 环境和签名发行仍未完成。原始需求文件和全部本地作者作品、构建产物、原始日志均不进入 Git。
