# 第十九轮：作者操作、输入保护与本地 AI 接力

日期：2026-10-27。版本：0.0.19。本轮将 N2 的有限作者链路与 N4 的首个本地工具实现合批，再集中构建与验证。证据分开记录代码、真实 HTTP、界面、原生系统和发行；不授予完整 G1/G2/AT 或 Windows 验收。

## 实现及缺陷修复

本地 AI 工具复用 Terre 原生 analysis/identity 和已有 `textSnapshot/saveTextSnapshot`，以稳定 ID 做有限对白修改/插入，保留未知内容和注释；提交核对提案审阅摘要、当前 revision、工作区、素材存在性和返回结果。提案在等待期间被调用方修改也不能改变私有审阅快照。CLI 仅接受 loopback，无模型账号/密钥、聊天、MCP、自动封存或自动运行路线。

Dashboard 名称/目录、Choose 手填标签、GameConfig 名称、Assets 文件/目录和 FileElement 重命名七处 Enter 回调增加组合态/229 保护。真实 TSX 回调测试先复现21项失败，修复后21/21，下一次普通 Enter 正常提交；这是事件边界验证，不是真实系统输入法。

共享场景分析识别首 BOM 而保留源字节与诊断位置。集中导演回归又发现未登记首节点无法编辑、已登记首节点改回原值失败；修复每节点 raw/originalRaw 和文件 BOM 的边界。保留 BOM、CRLF、稳定身份、注释及高级块。原生 parser 本体和运行时 HTTP 解码路径未改。

## 实际作者与 AI 接力

用户新开 Chrome 窗口后恢复控制。界面点击全部使用截图坐标，文字通过聚焦输入/粘贴；没有合成系统候选窗。创建原生作品 `makenovel-round19`（雨后书页 · 人工与 AI 接力），上传旧轮次原创SVG，创建空白story.txt；新建项目自带的start示例不算空白场景。

1. 图形新增首句，源码补背景/两立绘/变量/分支，回图形微调最后一句，登记其余身份并保存。首句ID在切换中保持，基线16节点。
2. 未知人物前缀得到保守诊断；明确改为 `say:... -speaker=羽;` 后通过。记录为现有安全边界，不静默转换。
3. 重建重启后重开已存场景。无父任务历史的新代理只读公共操作说明，经真实CLI/HTTP插入一句，节点新增为 `mn-57affb8a-05c5-4cc4-8bb9-dd2d200b81d5`。
4. Codex在图形界面给这句增加“轻轻”并保存。代理提交旧审阅提案实际得到 `REVISION_CONFLICT`（退出1），图形微调未丢。
5. 代理重新读取后审阅/校验/提交续写，保留“轻轻”且补“也记得今天的风。”。全部17ID同序，其余源码字节SHA256前后均为 `afb54aeba467f5ccea708da54e7582e78db6ad0efc7a0cd07b3e4bbd3baaf327`。
6. 故意引用不存在背景：validate报 `RESOURCE_NOT_FOUND`，commit报 `PROPOSAL_VALIDATION_FAILED`（退出1），全文/修订/ID未变。停止写入后，在图形界面检查磁盘版本并确认最终台词。

最终story revision：`e162066a811d380cf4b6647150f922bdb294d995a537f213f0ee527e8dcb19cf`。基线和编辑后保持CRLF，无无意增加BOM或裸LF。此接力是实服务操作，区别于46项工具自动测试；界面“人工路径”由Codex代操作，不声称用户本人操作或真实IME。
