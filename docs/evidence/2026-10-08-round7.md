## 产品范围

Terre 继续复用锁定原生 parser、图形语句编辑器、共享文档和保存事务。新“舞台与声音”面板只编辑单行普通对白及紧邻其前的既有安全背景、立绘/差分、BGM、SE 命令；等待与独立注释只读。局部草稿一次应用、共享历史整步撤销、过期文档拒绝写回，保存前保持预览隔离。它不插入或重排演出，不推算前文或分支继承状态，不提供完整时间轴。

WebGAL 仍使用原生舞台与存档。静态背景/立绘主图片的 pending、ready、failed 状态附着当前对象，setup 完成才 ready；对象 UUID 和本次请求身份阻止迟到结果污染新对象。普通/快速保存拒绝仍在加载或最终失败的主图，保留旧槽；辅助口型/眨眼纹理不改变主图状态。图片加载与脚本/演出时钟仍独立，没有全场景暂停、资源事务回滚或排队保存。详见 [舞台契约](../STAGE_LIFECYCLE.md)。

新生成器 `integrations/director-demo/` 创建独立作品，拒绝覆盖现有路径。复用源码生成的原创 SVG 和 PCM 测试音、锁定上游四个 GUI 模板与许可，未使用商业原作素材。首场景含 BOM、CRLF、行尾注释和显式 say 参数；故障场景的 `broken.svg` 存在且已封存，但故意不是有效图像，使完整性预检通过后能够测试实际解码失败。voice 文件仍是诊断音，不是真人配音。

资源门禁先执行旧代码红测试：首批相同 28 项套件加载第六轮原文件，结果 **6 通过 / 22 失败**，其中 pending/failed 主图的旧保存入口错误返回成功。修复后 **28/28**，覆盖正常/快速旧槽保留、静默自动快存、原生一次重试、缓存命中、实际立绘挂载异常、同步/异步 setup 异常、过时结果、辅助图隔离与重置。证据为 `resource-before-final-tests.log`、`resource-after.log`；旧失败是修复依据。

实际 GUI 随后发现坏 SVG 永久停在 pending：锁定 Pixi `SVGResource.load()` 的错误路径只 emit onError，不拒绝其 Promise。生产 asset parser 仅为实际 SVGResource 在调用 load 前订阅其 BaseTexture error；原生事件、Promise resolve/reject 或同步 throw 首次结算后精确移除本次监听，迟到拒绝被消费。parser 保留原 event/Error，失败沿原 catch 销毁纹理并清理缓存；非 SVG 保留原加载路径。锁定 Assets Loader 外层仍按上游行为包装错误。

新增 **10 项**测试直接使用真实锁定 Pixi SVGResource、BaseTexture、Texture 与生产 parser，Image/canvas 和 Assets 注册为边界替身。覆盖真实 onError 永久 pending 缺陷、成功/同步异常/拒绝的监听释放、原错误身份、迟到拒绝、并发隔离、非 SVG 成功/失败、实际资源类型识别，以及真实 Texture.from 同 URL 失败清理 TextureCache/BaseTextureCache 后重新创建。最终同 **38 项**在桥接前为 **31 通过 / 7 失败**，修后 **38/38**；分别见 `resource-svg-before-final-tests.log` 与 `resource-svg-after.log`。早期 37 项的 `resource-svg-before.log` 为 31/6，不混用为最终红测数量。

这次桥接针对原生 onError；SVG onload 内零尺寸或 drawImage 的异步抛错仍是上游边界，永久不触发回调的资源也没有超时策略。代码通过不意味着所有 SVG、资源插件或 GPU 异常已经受控。

早期并行构建会清理重建 parser 产物，一次 manifest 回归因此出现 `PARSER_UNAVAILABLE`；该次结果保留于 `manifest-build-race.log` 和 `runtime-suites-build-race.json`，不计为通过。待构建完成后按序执行，桥接前 runtime 329 项全部 exit=0；最终 SVG 构建后再次串行重跑得到 339/339。后续构建与依赖 parser 的测试继续串行，未通过改断言或放宽产品检查掩盖运行顺序问题。
