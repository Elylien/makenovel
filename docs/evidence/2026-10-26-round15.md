# 第十五轮：已有有限动画的导演编辑

日期：2026-10-26；版本 `0.0.15`。在锁定 WebGAL / Terre 上扩展原导演会话，不另建执行器或存档模型。

## 实现与边界

已有普通单行 `setAnimation` 可编辑动画资源、静态 target 和布尔 next，并与对白整批应用、撤销、保存。原生动画 JSON 决定关键帧和时长。目标支持 fig-left/center/right、bg-main 和非保留静态 ID；已知来源是模型或非静态素材时只读，未知/分支来源不推断为存在。

只接纳 target、next、缺省或 false 的 keep/parallel、缺省或 current 的 transformFrom。未知/重复/动态/条件、continue、旧参数、并行或跨句保留等保持只读或收集边界；动画不能新增、删除、移动或被邻行跨越。局部 token 写回保留身份、作者注释、BOM/CRLF 和显式 false/current；完整语义往返恢复原字节。表单使用最新原始缓冲，素材异步回调不覆盖较新的目标/next，组合输入结束后应用仍读取实际值。

独立审核发现已知模型目标可进入有限表单，现已在创建、刷新及通用写入路径增加来源保护，并补五项回归。来源仍以最近可确认命令为准，不模拟舞台或跨分支。非模型实际播放不证明模型支持。

## 实际浏览器路径

1. 打开动画导演表单、修改目标后取消，主文档保持已保存且无新撤销项。
2. 实际素材选择器保留 `nested.json/move.json-side` 内部后缀；`upper.JSON` 变成资源名 upper；最终选择 move-left。
3. target 改 fig-left、修改对白、切换 next，与资源一起一次应用；一次撤销恢复原稿，再重做。
4. 保存后只改变 start.txt 第 6、7 行；BOM、CRLF、注释、身份及其余字节保持。next 在编辑过程中显式变为 true，不声称该 token 拼写未变。
5. 刷新编辑器，资源 move-left、左侧目标和新对白仍正确。
6. 从标题正常开始，READY 快存；进入 MOVING 看到左侧蓝色人物移动。动画未结束时快存明确拒绝，旧 READY 槽未覆盖，快读恢复 READY。
7. 再次开始动画，提前点击先结算演出，仍停 MOVING，没有额外推进对白。
8. STABLE 快存后推进至 CLOSED，两人物关闭；快读恢复 STABLE、两人物及蓝色人物最终位置。
9. next=false 段在等待超过配置的 3000ms（观察间隔约 30s）后仍为 SECOND；点击后才到 MANUAL。不据此声称精确耗时。
10. 从正常剧情进入背景动画，背景标尺实际平移；平移后的黑色边缘属于样片可见结果。
11. 整页刷新、从标题正常开始，再快读恢复 STABLE。
12. readonly 场景的 keep 组合不进入新动画表单；模型只读保护本轮为代码证据，没有实际模型 GUI 验收。

截图 01–11 保存于本地证据目录并已查看。原 Round13 标签保留，临时播放器关闭，测试视口重置。GUI 未以作者跳句作为正常播放或存档证据。普通槽演出拒存本轮未单独实点，原生测试覆盖普通/快速门禁，不把快存 GUI 外推到所有槽。
