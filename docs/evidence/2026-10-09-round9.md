## 实现与审查

来源条目有具体源行时提供“定位来源”。局部会话无改动或未完成输入时，关闭导演面板，展开目标原生语句，在虚拟列表中滚动、聚焦并高亮，显示“返回原对白”。定位和返回不执行剧情、不保存、不编辑、不补登记 ID。返回后清除返回锚点，不形成隐含导航栈。

定位对绑定完整源码和历史代数；每次使用均核对真实身份、原文、原生命令与位置。未登记行仅用精确快照内的原文/位置，不把会话预留 ID 当作已登记身份。主文档 revision、实例、路径、生命周期、撤销重做 ABA 或卸载都会使旧定位失效。差分命令有具体来源但结果未知仍可定位；边界未知、未见来源不伪造目标。

点击定位先失焦提交原生输入缓冲，再读取实时 ref；局部修改、待选素材、错误输入和 IME 均保留面板并要求先应用或取消。异步焦点回调再次检查主文档输入、保存、冲突状态，避免排队后抢走 IME 焦点。这个竞态由独立审查发现，已增加无 React 重渲染窗口的回归。

锁定原生文件行单击即选材并关闭 portal。原先双击后续点击可落到 backdrop，触发导演 cancel 丢弃草稿；现对 Fluent `backdropClick` 阻止关闭。保留明确取消与非 IME 的 Escape，原生 Popover 先处理自己的 Escape；没有计时窗口或修改共享选材器。未宣称所有连续点击误点都消除。
