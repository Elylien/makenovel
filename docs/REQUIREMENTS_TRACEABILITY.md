## 记账约定

- 下列范围表的默认状态用于尚无增量证据的需求：上游状态＝待验证；项目状态＝未开始；实现位置＝未分配；测试结果＝未执行；证据＝无；人工复核＝未执行。已产生证据的 ID 以对应轮次的子项表为准；规划不表示设计完成，也不能仅勾父项。
- 可用产品状态：未开始、设计完成、原型完成、已实现、自动验证通过、待人工复核、整体验收通过。测试另用通过、失败、未执行、阻塞、待人工复核。
- “Gx→Gy”表示早期验证后到后期完整验收，优先顺序不豁免后续子项。
- 源章是私有需求章节号；N 系列为本账本给无原 ID 规范增补的主题索引；AT 为种子验收，实施时必须拆操作与边界，不能用一次构建替代。
- 下一动作：G0 项先核查两上游实际代码/版本并记录差异；G1 项先做有限实验；G2—G5 项待依赖成立后按开发计划接入真实流程。每项均在下表标出所属单元。
