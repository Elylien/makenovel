# 初始决策（2026-10-07）

1. **项目名暂为 MakeNovel / `makenovel`。** 可替换品牌，避免阻塞底座工作。用户已明确要求 Git 开源，使用当前 GitHub CLI 账户建立公开仓库；两份原文仅本地保存并按 SHA-256 校验复制结果。
2. **先锁定 WebGAL + Terre 4.6.5。** 记录实际 commit 与 yarn.lock，不假定相同版本号代表编辑器内置模板就是本地引擎提交。上游用 submodule 保存原样，改造需另行引入可审核补丁或 fork。
3. **保留原生剧本和执行器。** 稳定节点、素材描述与编辑组织可加元数据；不创建第二套剧情/存档真相。先做隔离的局部源码写回实验，再接入 Terre。
4. **首轮仅准备与可行性验证。** G0 构建、G1 源码实验与完整 G1 编辑流程分开记账。离线 Windows 成品验收尽早安排，但未执行不得写通过。
5. **参考固定为 Steam 中文 Windows 版《千恋＊万花》。** 用户在本次会话明确确认；具体 build、补丁及各功能交互继续核验。
6. **建议使用稳定检查点存档与会话取消机制。** 这是待实验决策，尚未替换上游实现；不承诺转场任意毫秒恢复。
7. **自有代码采用 MPL-2.0。** 上游及素材保留各自许可，工程开源不等于素材获得再发行许可。
8. **本地、无服务绑定。** 本阶段不引入模型 API、账户、付费服务或在线素材生成。开发预览绑定 loopback；未评估的上游写盘服务不暴露到局域网。

## 2026-10-07 第二轮：公开补丁与场景保存

- 保持上游 submodule 指针/依赖锁不变，根仓维护可核验并可重放的 Terre 补丁，避免依赖没有公开的子仓提交。
- 编辑器只启动单端口已构建前端与后端，绑定127.0.0.1并隔离作者 profile；原上游双端口 dev 不在本轮支持范围。
