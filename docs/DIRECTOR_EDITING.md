# 按对白编辑舞台与声音

第八轮在 Terre 原生图形编辑器的对白导演入口中增加四类命令的局部新增和前文来源参考。原生脚本仍是权威内容；新增、已有命令修改和本句对白共用一个面板草稿，应用时一次进入共享场景文档。

## 使用

在一条普通对白旁选择“舞台与声音”。面板展示本句及前面连续的背景、立绘、差分、BGM、音效命令；等待和独立注释只读。通过原有素材选择器和参数控件修改后，点击“应用到草稿”，再保存场景并执行到该句。整批应用可以一次撤销/重做。

“在本句前新增”提供背景、立绘、背景音乐和效果音。先选择完整素材，再设置原生参数；新行按添加顺序放在当前对白之前，位于该组原有命令和等待之后。新增立绘可指定左、中、右位置或自由立绘 ID；两种身份遵循原生语义。当前只接受静态图片和音频，不创建差分、模型、视频、动作或转场命令。

还未选择素材的项目不会生成占位命令，并阻止应用。选材后可以明确关闭该项；重新选择素材可恢复显示或播放。只能撤掉本次面板中新建的行。应用并重开面板后，这些行就是已有命令，不再提供“撤掉本次新增”；可以用共享文档撤销整个应用步骤。已有命令删除和全部重排仍需原有编辑方式。

Ctrl+S 在面板内仅应用到草稿，不写磁盘。取消不改变场景。未应用的面板输入只在内存中；刷新/关页有离开提示，但不会将其当作已经进入场景的持久恢复副本。应用后的场景草稿继续使用原有恢复机制。

面板打开期间暂停该作品的编辑器预览；关闭后，未保存场景仍沿原有门禁阻止预览。效果编辑器和依赖共享浮层的高级入口在面板内关闭，需回到原逐句编辑器操作。

## 前文来源参考

展开“本场景前文来源”，可查看当前对白之前最近可确认的背景、BGM、按位置或 ID 区分的立绘，以及最近效果音命令。条目标明源码行号和“本句前设置”或“较早前文”，随面板草稿更新；只查看来源不会为原行登记节点身份。

检查可经过普通对白、等待、空行和注释。遇到标签、分支、调用、变量赋值或插值、未知命令/参数、多行高级源码等边界就停止；边界之后的明确设置仍可列出，未能确认的更早来源显示未知。明确 `none` 与本场景尚无记录分别显示；没有记录不意味着运行时初始状态为空。

这些条目描述源码设置，不证明资源已上屏、音效仍在播放或当前舞台已完成恢复。差分命令显示其来源，但不推断最终图片；效果音记录也不推断持续时间或播放终态。面板不跨场景或跨分支还原舞台，不求值变量，不跳转到来源，也不从只读来源直接改写较早对白。需要覆盖前文设置时，在本句前新增命令。

## 边界与源码保留

已有命令只聚合当前对白前相邻的安全范围。碰到条件、分支、调用、未知参数/命令和多行高级源码时停止聚合，原源码保留。带条件或连续执行参数的对白不进入本面板；等待与注释不被自动移动。

每次修改按稳定节点身份重新定位，再使用原有局部 token 写回。打开时未登记的节点只在实际修改时登记，语义不变不会添加标记。新增行取得新身份；插入造成已有行的物理位置变化，不会因此登记或更换它们的身份。独立 legacy 标记继续与原节点绑定。未触及的注释、参数格式、BOM 和换行保留；现有 BOM 首行命令被分析为高级源码的限制仍在，首行可放注释。

最终应用同时核对打开时的完整场景草稿与历史代数。期间如发生源码编辑、重载、撤销或其他变更，旧面板拒绝覆盖并保留输入，需关闭后重新打开。主表单在批量应用后重同步；撤掉新行、取消选择或更新素材后，旧控件回调不能迁移到别的行。

## 验证和样片

纯会话回归执行真实原生 parser、插入/局部写回与共享文档；控件事件测试对 React/网络边界使用替身。代码功能不自动授予 GUI、Windows 或完整导演验收，实际结果以 [测试记录](TESTING.md) 和 [当前状态](PROJECT_STATUS.md) 为准。第七轮已有命令编辑的历史实测见 [第七轮证据](evidence/2026-10-08-round7.md)。

第八轮新增与来源样片使用独立目录：

```powershell
node integrations/director-insertion-demo/generate.mjs --output .local/editor-profile/games/<新的作品目录>
node --test integrations/director-insertion-demo/director-insertion-demo.test.mjs
```

目标必须不存在。样片先建立日景、双角色与 BGM，再留下没有局部舞台命令的 R8-02，供实际新增；R8-03 用于查看后续来源，末段包含标签及未知参数边界。其原生脚本保留 BOM、CRLF 和作者注释，作品身份与旧轮隔离。操作和来源见 [第八轮样片说明](../integrations/director-insertion-demo/README.md)。

第七轮资源故障样片仍由 `npm.cmd run demo:director -- --output .local/editor-profile/games/<另一个新目录>` 生成；其中故意损坏的图片只用于拒存验证。两套样片使用原创开发 SVG 和 voice 测试音，不是正式美术或真人配音。

后续仍需已有命令删除/重排、完整动作与转场控件、跨分支继承与来源跳转、直接舞台操作、AI 接力、真实 Windows 中文候选输入及复杂作者操作矩阵。
