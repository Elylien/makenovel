# 按对白编辑舞台与声音

当前版本 `0.0.12`。第十二轮在既有新增、等待编辑、来源定位和有限结构编辑上，增加静态背景的有限转场参数；已有背景和本次新增图片共用原生控件。原生脚本仍是权威内容；转场、等待、舞台设置和本句对白共用一个面板草稿，应用时一次进入共享场景文档。来源定位只改变图形编辑器的展开、滚动和焦点。

## 使用

在一条普通对白旁选择“舞台与声音”。面板展示本句及前面连续的背景、立绘、差分、BGM、音效和等待命令；普通静态等待可编辑，独立注释及不受支持的时序形式保持只读。通过原有素材选择器和参数控件修改后，点击“应用到草稿”，再保存场景并播放确认。整批应用可以一次撤销/重做。

“在本句前新增”提供背景、立绘、背景音乐和效果音。先选择完整素材，再设置原生参数；新行按添加顺序放在当前对白之前，位于该组原有命令和等待之后。新增立绘可指定左、中、右位置或自由立绘 ID；两种身份遵循原生语义。当前只接受静态图片和音频；新增背景可设置下述有限转场参数，不创建差分、模型、视频、动作或独立转场命令。

还未选择素材的项目不会生成占位命令，并阻止应用。选材后可以明确关闭该项；重新选择素材可恢复显示或播放。本次面板中新建的行使用“撤掉本次新增”；应用并重开后，它们成为已有命令，使用下述“移除设置…”与排序边界。

Ctrl+S 在面板内仅应用到草稿，不写磁盘。取消不改变场景。未应用的面板输入只在内存中；刷新/关页有离开提示，但不会将其当作已经进入场景的持久恢复副本。应用后的场景草稿继续使用原有恢复机制。

点击面板外部不会取消当前事务，避免原生素材选择器关闭后的第二次点击意外丢弃草稿。需要放弃修改时使用“取消”，或在中文候选输入结束后按 Escape。第九轮原生选择器双击 night.svg 后保留新增草稿的路径已有历史实测；其他连续点击组合仍以各自证据为准。

面板打开期间暂停该作品的编辑器预览；关闭后，未保存场景仍沿原有门禁阻止预览。效果编辑器和依赖共享浮层的高级入口在面板内关闭，需回到原逐句编辑器操作。

## 静态背景转场

已有或本次新增的普通单行 `changeBg`，使用静态 `png/jpg/jpeg/webp/svg` 图片且参数处于支持范围时，卡片内显示“背景转场”。修改三项时长后也可继续选择图片、修改本句对白，再整批应用；原生“连续执行”开关对应布尔 `next`。面板中的配置不会立即执行或预览，保存后从前一句正常播放检查结果。

| 字段 | 原生参数 | 作用与留空行为 |
| --- | --- | --- |
| 入场回退 | `duration` | 未配置入场时间时使用；留空移除此项覆盖 |
| 入场时间 | `enterDuration` | 优先于入场回退；两项均空时，当前引擎默认入场时间为 `1500` 毫秒 |
| 下次退场 | `exitDuration` | 这个背景之后被替换或关闭时使用；留空时当前引擎默认 `1500` 毫秒 |
| 连续执行 | `next` | 开启后立即处理后续命令，演出可能重叠；关闭后按原生玩家或自动播放方式推进 |

三项时长都支持空值或 `0–2147483647` 的十进制整数毫秒。空值移除参数，与明确的 `0` 不同；负数、小数、指数写法、超限值、变量及混入命令的文本不能作为此处的有效输入。选图、切换连续执行和应用前都会先检查完整时长缓冲，无效输入保留在面板中并阻止整批应用，其他行已填好的有效内容仍保留。

“下次退场”属于新背景之后的退出过程，不会改写当前旧背景已经持有的退场时间。同一图片仍在显示时，改参数不保证重建它；应切换到不同图片，或关闭后重新显示，再观察新的入场效果。图片加载、其他演出和输入都会影响实际观察，配置时长不等于整段播放耗时，也不能据此推导自动推进或精确计时。自定义全局默认效果仍可能改变实际呈现。

此转场区保守接受三项时长、布尔 `next`，以及通过原有校验的 `order` 参数；不开放其他参数组合。包含 CG 解锁名称 `unlockname`、系列 `series`、自定义入退场 `enter/exit`、变换/缓动、`ignoreDefault`、`continue`、重复参数、条件、变量或未知参数时，新转场区只读或该语句成为原有收集边界。视频、GIF、模型、明确关闭背景及动态资源也不开放这组控件。原文保留，需应用或取消面板后再使用原有编辑方式；原生素材控件的可用性不表示这些组合的转场编辑已经支持。

时长与连续执行使用原生参数和局部写回，不另造播放器状态。语义相同的输入不改原拼写或增加身份，整条背景命令完整改回原语义时恢复其原字节；未登记的已有行仅在实际改动时登记。只改时长不会丢失作者注释、换行或原身份，整批取消、应用后撤销/重做、过期文档与中文候选输入的门禁继续沿用。完整立绘转场、`setAnimation` 动作、曲线和时间轴仍为后续能力。

## 等待时长与执行顺序

本组已有的普通单行 `wait` 可修改等待时间和“禁止跳过”。时间单位是毫秒，支持 `0–2147483647` 的十进制整数；空值、负数、小数、指数写法、超出范围的值和变量表达式都不能作为本面板的有效输入。`nobreak` 仅支持原生布尔值，省略与 `false` 都表示允许提前跳过；`true` 表示禁止。等待的位置保持不变，本面板不新增、移除或移动等待，也不允许其他舞台命令跨越它。

开启“禁止跳过”会阻止点击和快进提前结束该等待；关闭后可由点击或快进截短。自动播放始终等待其结束。菜单打开期间计时仍继续；若在菜单中结束，后续剧情推进延后到菜单关闭。其他演出和运行状态仍可能影响实际停留，等待时间不是对整段播放耗时的承诺。

含 `next`（包括显式 `next=false`）、`continue`、条件、变量时长、未知或非布尔参数的等待不进入这组编辑能力；根据原有安全范围，它会显示为只读或成为收集边界。原文保留，需要时回到原有编辑方式处理。面板不会把变量求值成静态数字，也不会为了开放控件而移除参数。

等待修改沿用作者注释、BOM、换行和已有身份，独立 legacy 标记保持归属。未登记的等待仅在实际修改时登记身份；只打开面板或提交语义相同的值不改写源码。输入尚未完整、存在错误或中文候选输入未结束时，保留输入并阻止应用；修正后可继续。取消放弃整批面板修改，应用后的等待和其他设置仍能一次撤销/重做，保存才写入场景文件。

展开“执行顺序”可按源码查看本句之前的舞台设置、等待及本句对白，说明来自当前草稿配置。“立即继续”允许该演出与后续命令重叠，例如开启立即继续的 `800` 毫秒立绘切换后紧接 `2000` 毫秒等待，不能简单相加为 `2800` 毫秒。面板不累加总时长，也不从参数推断资源已经就绪或演出完成；实际效果应保存后从前一句正常播放确认。执行顺序说明不执行剧情，不改变源码，也不代替完整时间轴。

## 移除已有设置与相邻排序

本组已识别的单行背景、立绘、差分、BGM 和效果音卡片可使用“移除设置…”。先阅读原命令与影响说明，再选择“确认移除”或“保留该设置”。确认只改面板草稿；取消整个面板仍放弃本批修改。移除确认尚未处理时，不能应用、定位来源或继续调整别的设置。

移除命令表示它不再执行，不会自动补上 `none`，也不等于清空舞台或停止声音。移除本句最后一条背景、立绘或 BGM 设置可能重新显露较早前文，也可能因边界而来源未知；它会影响本句以及后续没有覆盖该项的对白。来源摘要随草稿重新计算，实际结果需保存后预览。差分和效果音仍只记录源码事实，不推断最终图片或持续播放状态。

命令的作者行内注释留为独立只读注释，不整理其中的标点和空格；只移除属于该命令的节点身份。独立 legacy 身份标记随所属命令删除，其他独立作者注释、等待和空行保留。留下的作者注释继续充当排序屏障。没有作者文字的纯身份标记不保留为孤立注释。

“上移”和“下移”只交换源码中紧邻的两个安全舞台命令块，保留各自的参数、作者行内注释、换行与已有身份。所属 legacy 身份随命令移动，不视为独立作者注释屏障。不能跨越等待、独立作者注释、空行、对白或不受支持的命令；按钮会标明不可移动的原因。排序不为未登记节点补 ID，也不替换已有 ID；字节完全相同的两行交换不产生改稿。

顺序决定原生执行先后。同位置的后一条立绘可能覆盖前一条，顺序也会改变命令自身的等待效果；面板不把命令重新解释为同时执行或自动合并。含变量插值、`continue`、条件、未知参数、多行或高级语法的设置不提供这类结构操作。可编辑参数并不自动意味着可以删除或排序。

操作前先让原生输入框提交失焦缓冲，再按当前草稿重新检查位置和身份。待选素材、无效输入或中文候选输入尚未结束时，保留输入并阻止结构操作。移除确认绑定所展示的局部源码；随后改动设置会使旧确认失效。主文档读取、保存、冲突或全文/历史代数变化时同样拒绝操作，撤销回相同文本也不能复用旧确认。取消或卸载后到达的操作、已删除行的迟到回调不能重新添加命令或修改别的行。

应用时删除、排序、插入及参数/对白修改合并为一次共享文档修改，可一次撤销到原源码，再一次重做。应用不代替磁盘保存；面板内没有单独的结构历史或自动运行剧情。

## 前文来源参考

展开“本场景前文来源”，可查看当前对白之前最近可确认的背景、BGM、按位置或 ID 区分的立绘，以及最近效果音命令。条目标明源码行号和“本句前设置”或“较早前文”，随面板草稿更新；只查看来源不会为原行登记节点身份。

检查可经过普通对白、等待、空行和注释。遇到标签、分支、调用、变量赋值或插值、未知命令/参数、多行高级源码等边界就停止；边界之后的明确设置仍可列出，未能确认的更早来源显示未知。明确 `none` 与本场景尚无记录分别显示；没有记录不意味着运行时初始状态为空。

这些条目描述源码设置，不证明资源已上屏、音效仍在播放或当前舞台已完成恢复。差分命令显示其来源，但不推断最终图片；效果音记录也不推断持续时间或播放终态。面板不跨场景或跨分支还原舞台，不求值变量，也不从只读来源直接改写较早对白。需要覆盖前文设置时，在本句前新增命令。

## 定位来源与返回

有具体源码行的条目提供“定位来源”。面板没有未应用或未完成输入时，点击会关闭面板，展开并滚动到原语句，同时显示行号与高亮。顶部“返回原对白”可回到打开该面板时的对白；返回后显示“已返回原对白”。定位不执行剧情，不保存场景，不登记节点身份，也不增加共享撤销步骤。

明确关闭的设置可以定位；结果未知但具有具体差分命令的条目也可以定位。因标签等边界而未知、或者本场景未见来源的条目不提供虚构目标。定位范围限当前场景已确认的源码，不追踪其他场景或运行时分支。

定位前先提交当前输入框的失焦缓冲，再检查面板草稿。存在局部修改、待选素材、输入错误或中文候选输入时，保留面板并提示先应用或取消。应用后如需定位，应从当前对白重新打开面板；定位不会代替应用，也不会默默丢弃局部草稿。

来源与返回位置绑定完整场景文本、历史代数、当前文档与路径。已登记行使用真实源码身份，未登记行只在该精确快照内按原文和位置核对。源码修改、撤销重做、重载、保存版本变化或切换场景后，旧定位失效；即使撤销回到相同文本，也不能复用旧返回位置。异步滚动后的聚焦再次检查文档状态，遇到输入法组合、读取、保存或冲突时不抢焦点。

## 边界与源码保留

已有命令只聚合当前对白前相邻的安全范围。碰到条件、分支、调用、未知参数/命令和多行高级源码时停止聚合，原源码保留。带条件或连续执行参数的对白不进入本面板；等待与注释不被自动移动。

参数和对白修改按稳定节点身份重新定位，再使用原有局部 token 写回。打开时未登记的节点只在这类实际内容修改时登记，语义不变不会添加标记。新增行取得新身份；插入或排序造成已有行的物理位置变化，不会因此登记或更换身份，删除未登记命令也不会先补 ID。独立 legacy 标记继续与原节点绑定。未触及的注释、参数格式、BOM 和换行保留；现有 BOM 首行命令被分析为高级源码的限制仍在，首行可放注释。

最终应用同时核对打开时的完整场景草稿与历史代数。期间如发生源码编辑、重载、撤销或其他变更，旧面板拒绝覆盖并保留输入，需关闭后重新打开。主表单在批量应用后重同步；撤掉新行、取消选择或更新素材后，旧控件回调不能迁移到别的行。
