# 按对白编辑舞台与声音

第七轮为 Terre 原生图形编辑器增加有限的导演入口，保留原生脚本、命令顺序、逐句控件和共享场景文档。它不是跨分支的舞台状态推演器，也不替代完整导演模式。

## 使用

在一条普通对白旁选择“舞台与声音”。面板展示本句及前面连续的背景、立绘、差分、BGM、音效命令；等待和独立注释只读。可以通过原有素材选择器和参数控件一起修改，点击“应用到草稿”后一次进入共享文档，再保存场景并执行到该句。整批应用可以一次撤销/重做。

Ctrl+S 在面板内仅应用到草稿，不写磁盘。取消不改变场景。未应用的面板输入只在内存中；刷新/关页有离开提示，但不会将其当作已经进入场景的持久恢复副本。应用后的场景草稿继续使用原有恢复机制。

面板打开期间暂停该作品的编辑器预览；关闭后，未保存场景仍沿原有门禁阻止预览。效果编辑器和依赖共享浮层的高级入口在面板内关闭，需回到原逐句编辑器操作。

## 边界与源码保留

只编辑已有命令，不新增、删除、重排或改写更早对白的继承状态。碰到条件、分支、调用、未知参数/命令和多行高级源码时停止聚合，原源码保留。带条件或连续执行参数的对白不进入本面板；等待与注释不被自动移动。

每次修改按稳定节点身份重新定位，再使用原有局部 token 写回。打开时未登记的节点只在实际修改时登记，语义不变不会添加标记。未触及的注释、参数格式、BOM 和换行保留；现有 BOM 首行命令被分析为高级源码的限制仍在，首行可放注释。

最终应用同时核对打开时的完整场景草稿与历史代数。期间如发生源码编辑、重载、撤销或其他变更，旧面板拒绝覆盖并保留输入，需关闭后重新打开。主表单也必须在批量应用后重同步，旧控件回调不能覆盖新内容。

## 验证和后续

纯会话回归执行真实原生 parser、局部写回与共享文档；控件事件测试对 React/网络边界使用替身。真实浏览器的修改、一次撤销/重做、保存重开与预览结果以 [本轮证据](evidence/2026-10-08-round7.md) 为准，不从代码测试推导 GUI 通过。

样片生成命令：`npm.cmd run demo:director -- --output .local/editor-profile/games/<新的作品目录>`。目标必须不存在。原创 SVG 和 voice 测试音沿用开发素材；样片还含已封存但无法解码的图片，用于验证资源失败拒存，不适合作为正式发行资源。

后续仍需新增演出、完整动作/转场控件、明确继承来源、直接舞台操作、AI 接力、真实 Windows 中文候选输入及复杂作者操作矩阵。
